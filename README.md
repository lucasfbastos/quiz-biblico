# Memorizando João

Quiz para memorizar o Evangelho de João, capítulo por capítulo. As perguntas que você ainda não acertou aparecem primeiro, e o progresso fica salvo no seu navegador.

**Acesse:** https://lucasfbastos.github.io/quiz-biblico/

## Como usar

- Escolha os capítulos no painel e comece uma rodada.
- Responda com as teclas 1–4 e avance com Enter.
- Funciona no celular e no computador, sem instalar nada.

## Rodar localmente

Baixe o repositório e abra o `index.html` no navegador.

## Observação

Texto das citações baseado na Almeida Revista e Atualizada. Confira sempre na sua Bíblia.
